OPTION 2: MANUAL DEPLOYMENT (STEP BY STEP)
═══════════════════════════════════════════════════════════════

STEP 1: OPEN TERMINAL
─────────────────────
Windows: 
  - Press Win + R
  - Type: cmd
  - Press Enter

Mac/Linux:
  - Open Terminal app

STEP 2: NAVIGATE TO PROJECT
────────────────────────────
cd /ozysparda/Dayang-Spa-Resto/HEAD

STEP 3: COMMIT CHANGES
───────────────────────
git add .
git commit -m "fix: Profile page data structure and enhanced error handling"

STEP 4: PUSH TO GITHUB
───────────────────────
# If you have a remote already:
git push origin main

# If you need to add remote first:
git remote add origin https://github.com/YOUR-USERNAME/YOUR-REPO.git
git push -u origin main

STEP 5: INSTALL VERCEL CLI
───────────────────────────
npm install -g vercel

STEP 6: LOGIN TO VERCEL
────────────────────────
vercel login
# Follow the authentication prompts

STEP 7: DEPLOY TO VERCEL
─────────────────────────
vercel --prod

STEP 8: FOLLOW PROMPTS
───────────────────────
- Link to existing project? Choose: No (for first deploy)
- Project name? Press Enter (use default)
- In which directory is your code? Press Enter (use current)
- Want to override settings? No
- Wait for deployment...

OPTION 3: VERCEL DASHBOARD DEPLOYMENT
═══════════════════════════════════════════════════════════════

1. Go to: https://vercel.com/new

2. Click "Import Git Repository"

3. Select your GitHub repository

4. Configure:
   Root Directory: ./
   Build Command: npm run build
   Output Directory: client/dist
   Install Command: npm install

5. Add Environment Variables:

   NODE_ENV=production
   JWT_SECRET=your-super-secret-key-here-change-this-in-production
   DATABASE_URL=your-neon-postgresql-connection-string
   CLIENT_URL=https://your-app.vercel.app
   VITE_API_URL=https://your-app.vercel.app/api

6. Click "Deploy"

TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

PROBLEM: "git: command not found"
SOLUTION: Install Git from https://git-scm.com/downloads

PROBLEM: "vercel: command not found"
SOLUTION: Run: npm install -g vercel

PROBLEM: Build fails on Vercel
SOLUTION: Test locally first: npm run build

PROBLEM: Database connection error
SOLUTION: 
  1. Check DATABASE_URL in Vercel environment variables
  2. Ensure Neon database is running
  3. Verify connection string is correct

PROBLEM: Profile page still shows error
SOLUTION: 
  1. Check browser console (F12)
  2. Verify API endpoint: https://your-app.vercel.app/api/auth/me
  3. Check Vercel function logs
